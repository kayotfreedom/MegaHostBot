# Telegram-бот «MegaHost» (Хостинг юзер-ботов)

Telegram-бот на базе aiogram (v3), представляющий собой панель для покупки, управления и продления юзер-ботов (Hikka, Heroku). Бот позволяет пользователям приобретать тарифы, выбирать серверы (США, Германия), управлять доступом к своим ботам и получать ежедневные бонусы.

## 🤖 Основной функционал

### Для пользователей (Магазин и управление):
- Покупка юзер-бота: Выбор тарифа (Standard, Lite), образа (Hikka, Heroku) и сервера (USA-1/2/3, DE-1/2/3). Оплата списывается с внутреннего баланса.
- Мои юзер-боты: Просмотр списка активных ботов, статуса их серверов и ID владельца.
- Управление ботами: Возможность продлить тариф, перенести на другой сервер или удалить юзер-бота с хостинга.
- Профиль и баланс: Просмотр баланса, ID, количества приглашенных рефералов. Начисление 10% от трат рефералов.
- Ежедневный бонус: Возможность раз в 24 часа получить случайную сумму на баланс.
- Пополнение: Раздел для пополнения баланса (в текущей версии через администратора).

### Для администраторов:
- Панель управления: Доступ по команде /admin.
- Управление валютой: Ручное начисление и списание рублей пользователям.
- Рассылки: Отправка сообщений всем или только тем, кто не привел рефералов.
- Управление каналами: Добавление/удаление ID каналов для обязательной подписки.
- Промокоды: Создание и деактивация промокодов.

## 📂 Структура проекта

```text
├── main.py               # Основной файл бота (роутеры, хэндлеры, логика)
├── database.py           # БД пользователей, баланса, рефералов, промокодов
├── settings.py           # Конфигурация (токен, админы, каналы)
├── count_session.py      # Скрипт для поиска и подсчета свободных папок (сессий)
├── Userbots/             # Папка с шаблонами для развертывания ботов
│   └── Hikka/            # Шаблоны папок hikka 1, hikka 2 и т.д.
└── README.md             # Документация проекта
```
## 🛠️ Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10 или выше.

pip install aiogram

### 2. Настройка settings.py
Откройте файл settings.py и укажите свои данные:
- TOKEN — токен бота (от @BotFather).
- channel_ids — список ID каналов для обязательной подписки.
- admins — список ID администраторов.

### 3. Подготовка папок
Убедитесь, что в директории с ботом создана папка Userbots/Hikka, внутри которой лежат готовые шаблоны папок (например, hikka 1, hikka 2). При покупке бот переименует одну из них под ID пользователя.

### 4. Запуск
При первом запуске автоматически создастся файл database.db и таблицы. Запустите бота командой:

python main.py

## ⚠️ Важные технические замечания

1. Смешение версий aiogram: В конце файла main.py находятся строки from handlers.ignore_blocked import ... и executor.start_polling(...). Это синтаксис из aiogram 2.x. В aiogram 3.x они не работают, и их следует удалить.
2. Работа с файловой системой: Функция search_hikka и логика переименования папок завязаны на конкретный путь в Windows (C:/Users/...). Для запуска на сервере (Linux) пути в count_session.py и main.py потребуется адаптировать.
3. Безопасность: Токен, указанный в файле, скомпрометирован (находится в открытом виде в тексте). Для реальной работы сгенерируйте новый токен в BotFather и используйте .env файл.
